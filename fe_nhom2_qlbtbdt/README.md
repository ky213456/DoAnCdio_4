# FE_NHOM1_QLBTBDT

> **Giao diện Người dùng (Frontend) Website Quản Lý Bán Thiết Bị Điện Tử Tích Hợp AI Tư Vấn Khách Hàng**

---

## 📌 Giới thiệu Dự án
- **Đề tài:** Website quản lý bán hàng thiết bị điện tử tích hợp AI tư vấn khách hàng.
- **Nhóm thực hiện:** Nhóm 1
  - **Trưởng nhóm / Scrum Master:** Nguyễn Văn Kỳ
  - **Thành viên:** Võ Đình Huy, Lê Quốc Khánh, Phạm Tiến Ninh, Dương Văn Trọng Đại
- **Công nghệ Frontend:**
  - **Framework:** Vue 3 (Composition API)
  - **Build Tool:** Vite
  - **Ngôn ngữ:** JavaScript / HTML5 / CSS3

---

## 🚀 Hướng dẫn Cài đặt & Chạy Dự án

### 1. Cài đặt các gói thư viện
```bash
npm install
```

### 2. Khởi chạy môi trường phát triển (Hot-Reload)
```bash
npm run dev
```
Mặc định ứng dụng sẽ chạy tại: `http://localhost:5173`

### 3. Đóng gói cho môi trường Production
```bash
npm run build
```
